The text is the site. key: value lines at the top are settings; # Heading starts a section; chart: bars plus indented options draws a chart from a SQL query against your data. The preview updates as you type.

Drop CSV files here, or . Each file becomes a table named after it.

Charts read columns by name: label/value for bars and waffles, x/y(/series) for lines, iso2/value for maps. Use AS in the query to rename.

Import the zone file at your DNS host (or paste the records), then point the domain at a loader with a CNAME to dnsite.pages.dev (or an A record for a bare domain). Check the domain asks public DNS whether every record has landed.

Drop SVG, PNG, JPEG or WebP files here, or . They are stored inside the site's records.

SVGs are cleaned and made safe; photos are re-encoded as WebP at the width above. Every image costs records: a logo is a few, a photo twenty or more. For big pictures, use an image block with a URL instead and keep them on a host you already have.

Publish to Cloudflare

Works when the domain's DNS is on Cloudflare. Make a token at My Profile → API Tokens → Create Token → "Edit zone DNS" with Zone Resources: Include → Specific zone → your domain. The token is used from this browser through a pass-through on dnsite.org that stores nothing.

Import the zone file at your DNS host (or paste the records), then point the domain at a loader with a CNAME to dnsite.pages.dev (an A record for a bare domain). Check the domain asks public DNS whether every record has landed.
